# Flow: Recipe Discovery & Meal Planning

## Flow Diagram

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  Discover    │     │   Recipe     │     │ Add to Meal  │
│  Feed        ├────▶│   Detail     ├────▶│ Plan         │
└──────────────┘     └──────────────┘     └──────┬───────┘
                                                 │        
                                                 ▼        
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  Shopping    │     │  Weekly      │     │              │
│  List        │◀────┤  Meal Plan   │◀────┤ Empty State  │
│              │     │              │     │              │
└──────────────┘     └──────────────┘     └──────────────┘
```

Screens to wireframe:

1. Discover Feed — User browses recipes by category with images and cook times
2. Recipe Detail — User reads ingredients and step-by-step instructions
3. Add to Meal Plan — User assigns a recipe to a day and meal slot
4. Weekly Meal Plan — User views their 7-day meal plan grid
5. Shopping List — User checks off auto-generated ingredients
6. Empty State — New user with no meal plan is prompted to browse recipes
