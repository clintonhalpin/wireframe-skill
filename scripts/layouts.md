# Wireframe Template Library

A reference library of 50 common web design patterns as ASCII wireframes.

## Conventions

### Block characters (gray box style)

| Character | Represents                | Example                       |
| --------- | ------------------------- | ----------------------------- |
| `████`    | Heading / title           | `██████████████████`          |
| `░░░░`    | Body text / paragraph     | `░░░░░░░░░░░░░░░░░░░░░░░░`    |
| `▓▓▓▓`    | Image / media / avatar    | Block of `▓` filling the area |
| `▒▒▒▒`    | Secondary text / metadata | `▒▒▒▒▒ · ▒▒▒▒`                |

### Interactive elements (keep as real text)

- `[Button Label]` — primary action
- `(Button Label)` — secondary action
- `< Back` / `Next >` — navigation actions
- `[x]` / `[ ]` — checkbox states
- `( )` / `(*)` — radio states
- `[_______________]` — text input field
- `[v]` — dropdown/select
- `...` — truncated or repeating content
- `*` — active/selected indicator

### What stays as text

Nav items, field labels, column headers, tab labels, section names, button labels, inputs, dropdowns.

### What becomes block characters

All `{Text}` style placeholders — use the appropriate block character instead.
